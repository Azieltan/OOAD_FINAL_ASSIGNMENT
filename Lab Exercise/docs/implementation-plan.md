# Hospital Management System MVP Implementation Plan

**Goal:** Build a Java Swing Hospital Management System MVP that satisfies the lab PDF and is easy to demonstrate in a 10-15 minute presentation video.

**Architecture:** Use an in-memory repository, service classes for business rules, a controller facade for the GUI, and Swing frames for login/dashboard workflows. Keep source code package-organized and include UML/documentation artifacts for submission.

**Tech Stack:** Java 22, Java Swing, plain `javac`/`java`, PlantUML text files.
